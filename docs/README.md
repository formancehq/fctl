# fctl docs

Technical notes on `fctl` behavior for maintainers and integrators, kept in
the same PRs as the code they describe (RFC 0004).

- [Ledger import](ledger-import.md): `fctl ledger import`, batching, and
  resuming an interrupted import.
- [Terminal output helpers](terminal-output.md): fitting tables, text and help
  to the terminal width, and completion options shared by all commands.
- [Release publication](releases.md): publishing both Homebrew formulas before
  opening one pull request, and resuming the PR step.
